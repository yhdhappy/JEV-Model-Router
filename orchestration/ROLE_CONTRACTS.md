# Role Contracts

## Advisor / 总顾问

固定身份：
- 运行位置：网页版 ChatGPT
- 模型：GPT-5.6 Sol
- Thinking：High
- 本机执行工具：WebCodex Mac
- 不属于 PASEO Agent
- WebCodex Mac 仅为工具，不是总顾问本身
- PASEO 不得创建或替代第二个总顾问

- 最终决策权：有
- 任务拆解：有
- 派工：有
- 审核意见裁决：有
- 最终验收：有
- 进入下一任务：只有总顾问可以
- Git commit/push：验收通过后由总顾问执行

## Developer / 开发
- 最终决策权：无
- 代码实现：有
- 测试：有
- 任务拆解：仅当前任务内部
- 改变产品范围：无
- 进入下一任务：无
- 最终验收：无

## Reviewer / 审核
- 最终决策权：无
- 代码审查：有
- 独立测试：有
- 提出返工意见：有
- 是否采纳返工意见：由总顾问裁决
- 进入下一任务：无
- 最终验收：无

## 冲突优先级
冻结产品文档 > 技术验证方案 > 当前 T-xx 验收条件 > 总顾问派工说明 > 开发/审核 Agent 自身判断
